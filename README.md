# Gardiáns do Clima

Videoxogo educativo para **4º de Primaria**, en **galego**, pensado para **pizarra dixital táctil**.
Trabaja la Unidad 2 de Ciencias Sociais: *O tempo e o clima*.

▶️ **Jugar en el navegador (sin instalar nada):** https://TU_USUARIO.github.io/gardians-do-clima/
También disponible en itch.io: https://saracasares.itch.io/gardians-do-clima

> La primera carga tarda unos 30-40 segundos (el navegador descarga Python). El sonido se activa tras el primer toque.

## Misiones

| Misión | Contenido |
|---|---|
| 1. A atmosfera e o tempo | Atmósfera, fenómenos atmosféricos, ciclo del agua, mapa del tiempo |
| 2. Elementos e factores | Elementos del clima e instrumentos, latitud, altitud, mar y relieve |
| 3. Os climas de España | Zonas climáticas de la Tierra y climas de España |
| 4. Os climogramas | Leer, completar y comparar climogramas |
| 5. As paisaxes | Paisajes de España, vegetación e incendios |
| 6. O clima de Galicia | Variedades del clima oceánico y estación meteorológica |
| 7. O clima está cambiando | Cambio climático, medidas y TIX + batalla final |

Todo se juega tocando y arrastrando: clasificar tarjetas, unir con flechas, ordenar, colocar en mapas, completar climogramas y responder preguntas.

## Contenido del repositorio

- `index.html`, `videojuego.apk`, `videojuego.tar.gz`, `favicon.png`: versión web del juego (generada con [pygbag](https://github.com/pygame-web/pygbag)).
- `codigo/`: código fuente en Python ([pygame-ce](https://pyga.me/)). Para jugar en el ordenador: `pip install pygame-ce` y `python codigo/main.py`.
